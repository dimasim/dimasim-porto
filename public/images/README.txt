Folder ini disiapkan untuk menyimpan aset gambar portofolio Anda:

1. Foto Profil:
   Simpan foto Anda di sini dengan nama:
   profile.jpg (atau /images/profile.jpg)

2. Gambar / Screenshot Proyek:
   Anda dapat menyimpan gambar preview proyek di sini, contoh:
   - /images/lstm-autoscaling.png
   - /images/psikotes.png
   - /images/smarthome.png

Lalu isi path gambar tersebut pada file `src/pages/index.astro` di dalam array `projects`.
